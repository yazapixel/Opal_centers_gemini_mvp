# 💎 Opal Centers (مركز أوبال) - MVP Website

A luxury, responsive MVP website for **Opal Centers (مركز أوبال)**, a premier beauty, skincare, laser, and wellness center located on **Al-Aziziya Street (opposite Africa Pharmacy), Benghazi, Libya**.

## ✨ Features & Architecture
- **Luxurious Aesthetic Design:** Crafted with a sophisticated rose-gold and deep charcoal palette (`#C5A059`, `#1A1A1A`), custom typography (Tajawal & Playfair Display), and responsive flex/grid layouts.
- **Comprehensive Service Catalog:** Skincare & HydraFacial, Laser Hair Removal, Hair Styling & Treatments, Spa & Moroccan Bath, Bridal Makeup Packages, and Nail Care.
- **Interactive Booking System:** Modal popup with service pre-selection, date picker, form validation, and confirmation success screen.
- **Location & Contact Details:** Integrated Google Maps location linking directly to the exact map pin, operating hours, phone/WhatsApp contacts, and customer inquiry form.
- **Bilingual & RTL-first:** Optimized for Arabic-speaking clientele in Benghazi with crystal-clear typography and layout.

## 🚀 Getting Started & Testing
1. Open `index.html` in any modern web browser or serve locally:
   ```bash
   python3 -m http.server 8000
   ```
2. Run automated verification tests:
   ```bash
   python3 test_mvp.py
   ```
